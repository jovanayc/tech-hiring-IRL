# Tech Hiring IRL

Live event page for The Dev Difference's Tech Hiring IRL night. No login needed.

| **Room screen** (all groups, for the big display) | https://jovanayc.github.io/tech-hiring-IRL/#screen |

## How to use the event page

1. Open the event page on your phone.
2. When a round starts, the page shows "Round 1 has started," the countdown and every group.
3. Enter your first and last name to see just your station color, who you are meeting and the icebreaker.
4. Before you leave, tap "Take the exit survey" on the same page and rank who you want to keep talking to. The button appears once the team opens the survey.

You need to be checked in at the desk before your name is placed in a group.

## About this repository

This repository holds only the public attendee page, served with GitHub Pages. Event data lives in Supabase. The team console is kept in a separate private repository.
